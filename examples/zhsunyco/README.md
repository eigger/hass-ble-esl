# Zhsunyco (WOLINK / easyTag) examples

No examples have been contributed for Zhsunyco tags yet.

The [`../gicisky`](../gicisky) examples are a good starting point — the payload
format is identical, only the resolution differs. Common Zhsunyco presets:

| Size | Resolution | Colors |
|------|------------|--------|
| 2.13" | 250 × 122 | BWRY / BWR |
| 2.90" | 296 × 128 | BWRY / BWR |
| 4.20" | 400 × 300 | BWRY / BWR |
| 7.50" | 800 × 480 | BWRY / BWR |
| 10.2" | 960 × 640 | BWRY / BWR |

If you have a working automation, please open a PR adding `<size>-<name>.yaml`
plus a photo or preview image alongside it.
